## Project

- This repository contains the CCK site.
- The site is for people who visit and use CCK's website.

## Stack & constraints

- The site is built with Astro.
- Content is managed with Astro content collections.
- The project does not use a CSS framework.
- Prefer Astro components and content collections over duplicated markup or content.
- Use semantic, accessible HTML and preserve responsive behavior.
- Keep styles in plain CSS and follow existing project conventions.
- Reuse existing components and utilities before creating new ones.
- Keep changes focused and avoid unnecessary dependencies.
